=======
Filters
=======

This module contains digital signal processing filters used within the Taproot library. It includes discrete filter architectures, coefficient generators, state estimators, and simple utility filters.

.. contents:: Table of Contents
   :local:
   :depth: 2

Kalman Filter
-----------------
The Kalman Filter is an optimal recursive data processing algorithm used to estimate the state of a dynamic system from a series of noisy measurements. It is built upon the CMSIS DSP library for efficient matrix operations.

.. doxygenclass:: tap::algorithms::KalmanFilter
   :project: taproot
   :members:

Extended Kalman Filter
----------------------

This is a SISO version of the Kalman filter, it currently doesn't support things that a full EKF would such as non-linear process and measurement models.
This will be expanded in the future to support more complex use cases.

Mahoney AHRS
-----------------
The Mahoney AHRS (Attitude and Heading Reference System) is an algorithm used to compute the orientation of an object in 3D space using data from a gyroscope and accelerometer.

Butterworth Filter
------------------

The Butterworth filter implementation provides tools to generate coefficients for Low-pass, High-pass, Band-pass, and Band-stop filters. It utilizes the Bilinear Transform to map analog prototypes to the discrete Z-domain.

The coefficients generated by this module are designed to be passed into the ``DiscreteFilter`` class documented above.
